# Сервер "Отслеживание посылок"
## Описание:
Реализована система логистики с функциями определения получателя, адреса доставки, отслеживания статуса и истории посылок. Автоматизирует процесс управления доставкой.

## Инструкция по запуску:
1. Клонировать репозиторий командой
   >`git clone git@github.com:Diggity09/final-main.git`
2. Открыть скачанный репозиторий через редактор.
3. Ввести команды:
   >`go test .`
   >
   >`go run main.go`
